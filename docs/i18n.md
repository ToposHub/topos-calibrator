# 国际化 (i18n) 指南

Topos Calibrator 采用统一的轻量国际化方案：**以中文原文作为翻译 key**。
中文是源语言（无需维护字典），其他语言通过语言包文件映射；任何未收录的词条自动回退显示中文原文，因此翻译可以渐进补齐，不会出现"key 名"暴露给用户的问题。

当前支持：**简体中文**、**English**。首次启动时会检测系统语言：中文系统使用简体中文，其余系统使用 English；之后保留用户手动选择的语言。

## 架构总览

| 层 | 核心模块 | 语言包 |
|---|---|---|
| Web 主界面 (QWebEngine) | `web/js/i18n.js` | `web/js/locales/<lang>.js` |
| Python 后端 (QWebChannel 消息 / Qt 窗口) | `src/i18n/__init__.py` | `src/i18n/locales/<lang>.json` |

两端共享同一套设计约定（key、`{name}` 占位符、回退行为），语言偏好统一存放在：

- Web 端：`localStorage["topos.lang"]`（切换即时生效，整个 DOM 重译）
- Python 端：`QSettings("topos", "ToposCalibrator")/language`（Web 切换时经 `backend.setLanguage()` 同步）

用户入口：**设置菜单 → 简体中文 / English**。

## Web 端

### 工作原理

1. `i18n.js` 首先加载，按 `localStorage → navigator.language → zh-CN` 的顺序确定初始语言；
2. 语言包文件（`locales/zh-CN.js`、`locales/en.js`）调用 `I18N.register(lang, dict)` 注册字典；
3. DOM 遍历器翻译页面中所有**文本节点**及 `title` / `placeholder` / `aria-label` / `data-desc` 属性；
4. **MutationObserver** 监听后续动态插入的节点（JS 拼 HTML、textContent 更新等），自动翻译新增内容；
5. 切换语言时：持久化 → 重建字典 → 全量重译 DOM → 触发 `I18N.onChange` 回调（图表重绘等）。

因此**绝大多数界面文字无需改代码**，只要把中文文案加进语言包即可被翻译。

### 代码中的翻译写法

```js
// 简单文案（静态 HTML 里的文字不需要包，DOM 遍历器会处理）
updateStatus(t('已连接到后端'));

// 含变量（JS 端必须用 t() + 占位符，DOM 观察器无法匹配"值+中文"混合文本）
updateStatus(t('已加载 {n} 条测量数据', {n: count}));
```

规则：

- **alert / confirm / prompt** 中的文字必须用 `t()` 包裹（原生对话框不经过 DOM）；
- **「变量 + 中文」组成的纯文本**必须用 `t()` 包裹；
- **纯 HTML 模板中的静态中文**不用包（Observer 自动翻译）；
- **用于逻辑判断/数据 key 的中文**（如色块名 `'红'`、`series.name === '测量点'`）**绝对不要包**——内部值始终保持中文，只翻译显示层；
- ECharts 的 series 名保持中文，图例显示用 `legend.formatter` 翻译（参见 `charts.js`）。

### Python 端写法

```python
from src import i18n   # 包内用 from . import i18n

self.logMessage.emit(i18n.t("探头已连接"))
i18n.t("已加载 {n} 条记录", n=3)
```

带 `{...}` 插值的 f-string 消息请改成 `t()` + 关键字参数；调试日志（`>>>`、`===`、`console.*`）不需要翻译。

## 如何新增一种语言（以日语为例）

1. **Web 语言包**：新建 `web/js/locales/ja.js`：

   ```js
   (function (global) {
       'use strict';
       global.I18N.register('ja', {
           '已连接到后端': 'バックエンドに接続しました',
           // ...更多词条，可先只翻译高频文案，其余自动回退中文
       });
   })(window);
   ```

2. **Python 语言包**：新建 `src/i18n/locales/ja.json`（同格式，UTF-8 JSON）。

3. **登记语言**（两处）：
   - `web/js/i18n.js` → `supportedLanguages` 数组加 `{ code: 'ja', name: '日本語' }`；
   - `src/i18n/__init__.py` → `SUPPORTED_LANGUAGES` 加 `("ja", "日本語")`。

4. **挂载脚本**：在 `web/index.html` 和 `web/comparison.html` 中、`locales/en.js` 之后加：

   ```html
   <script src="js/locales/ja.js?v=1"></script>
   ```

5. **切换菜单**：在 `web/index.html` 的设置菜单中仿照 `menu-language-en` 增加条目，并在 `web/js/main.js` 的 `switchLanguage` / `updateLanguageMenu` 中接线。

完成后 `设置` 菜单即可切换到新语言。单元测试 `tests/test_i18n.py` 会校验语言包的完整性约束。

## 补充翻译词条的流程

1. 运行应用，把界面切到目标语言，记录仍显示中文的文案；
2. 将 `中文原文` → `译文` 加入对应语言包（注意**逐字一致**，含标点与空白）；
3. 若是「值+中文」混合文本，先在 JS/Python 源码中改成 `t('...{name}...', {...})` 再加词条。
