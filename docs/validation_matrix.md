**文档版本**: 1.0

## 1. 验证范围

### 1.1 探头覆盖

| 探头型号 | 类型 | 技术特点 | 验证优先级 |
|---------|------|---------|-----------|
| i1Display Pro | 色度计 | 高速、广色域、支持 CCSS | P0 (必须) |
| i1Pro 2 | 分光光度计 | 高精度、含校正 | P0 (必须) |
| i1Pro 3 | 分光光度计 | i1Pro 2 升级版 | P1 |
| SpyderX | 色度计 | 新传感器、需校正矩阵 | P1 |
| ColorMunki Display | 色度计 | 入门级、与 i1Display Pro 同技术 | P2 |
| Spyder5 | 色度计 | 旧款、仍有用户 | P2 |

### 1.2 显示器覆盖

| 显示器类型 | 技术特征 | 典型代表 | 验证优先级 |
|-----------|---------|---------|-----------|
| sRGB LCD | 标准 sRGB 色域、W-LED 背光 | Dell U2415、NEC EA245 | P0 (必须) |
| 广色域 LCD | AdobeRGB/P3、量子点/IPS | Dell U2720Q、LG 27UP850 | P0 (必须) |
| OLED | 像素级控光、ABL、近零黑场 | LG C系列、Dell UP3017Q | P0 (必须) |
| HDR/miniLED | 分区背光、高亮度、HDR模式 | Apple Pro Display XDR、Samsung Odyssey Neo | P1 |
| 投影仪 | DLP/LCD 技术、环境光影响大 | BenQ 投影仪 | P2 (后续) |

### 1.3 操作系统覆盖

| 操作系统 | 版本要求 | 特殊考虑 | 验证优先级 |
|---------|---------|---------|-----------|
| macOS | 12.0+ (Monterey) | USB 权限、屏幕录制权限、Night Shift | P0 (必须) |
| Windows 11 | 22H2+ | HDR/ACM、驱动签名、DDC/CI | P0 (必须) |
| Linux | X11 环境 | i2c-dev 权限、Wayland 限制 | P1 |

## 3. 验证项详细定义

### 3.1 探头检测 (Instrument Detection)

**验证内容**:
- 系统正确识别探头型号
- USB 连接状态正常
- 探头固件版本可读取

**通过标准**:
- 预检界面显示探头型号
- 无 USB 权限错误
- 可以启动探头校准流程

**失败后果**: BLOCK - 无法继续后续验证

---

### 3.2 探头校准 (Instrument Calibration)

**验证内容**:
- 探头能够执行自校准
- 校准数据正确保存
- 校准历史可追溯

**通过标准**:
- 校准流程正常完成
- 无超时或错误
- 校准结果在预期范围内

**失败后果**: BLOCK - 测量数据不可信

---

### 3.3 预检完整性 (Preflight Completeness)

**验证内容**:
- ArgyllCMS 工具链检测
- 显示器索引识别
- 系统权限检查
- 环境干扰检测（Night Shift/True Tone 等）

**通过标准**:
- 所有 BLOCK 级别问题已解决
- WARN 级别问题已知晓并确认
- 预检报告可导出

**失败后果**: BLOCK 或 WARN（取决于具体项）

---

### 3.4 原生测量 (Native Measurement)

**验证内容**:
- 单色块测量准确性
- 灰阶测量连续性
- 色域采样覆盖率
- 测量稳定性（重复性）

**通过标准**:
- 测量结果与参考值 Delta E < 3.0（色度计）或 < 1.0（分光光度计）
- 重复测量标准差 < 1.0 dE
- 灰阶无异常跳变

**失败后果**: WARN 或 BLOCK - 数据不可信需排查

---

### 3.5 ICC 生成 (ICC Profile Generation)

**验证内容**:
- ICC 文件格式正确
- 包含必要的 tag（desc, wtpt, rXYZ, gXYZ, bXYZ, rTRC, gTRC, bTRC, A2B0 等）
- 文件可被系统加载
- 与 DisplayCAL/Argyll 原生命令结果可比

**通过标准**:
- ICC 文件通过 `iccVerifyProfile` 检查
- 系统可正确加载并应用
- 色域形状与预期一致

**失败后果**: BLOCK - 校准结果无法使用

---

### 3.6 ICC 验证 (ICC Profile Verification)

**验证内容**:
- 校准后测量与目标对比
- 平均 Delta E
- 最大 Delta E
- 色域覆盖率变化
- Gamma/EOTF 曲线吻合度

**通过标准**:
- 平均 Delta E < 2.0
- 最大 Delta E < 5.0
- Gamma 偏差 < 0.1
- 白点偏差 Delta E < 2.0

**失败后果**: WARN - 校准质量不达标，需重新校准或调整参数

---

### 3.7 3D LUT 生成 (3D LUT Generation)

**验证内容**:
- LUT 文件格式正确（.cube 等）
- LUT size 正确（33/65 点）
- 源/目标色域正确
- 渲染意图正确应用

**通过标准**:
- LUT 文件可被目标软件加载
- 格式校验通过
- 包含正确的元数据

**失败后果**: BLOCK - LUT 无法使用

---

### 3.8 3D LUT 验证 (3D LUT Verification)

**验证内容**:
- LUT 应用后测量结果
- 色域映射准确性
- 色彩保真度
- 灰阶中性

**通过标准**:
- 平均 Delta E < 2.0
- 色域边界无明显裁剪伪影
- 灰阶 Duv < 0.005

**失败后果**: WARN - LUT 效果不理想

---

### 3.9 报告导出 (Report Export)

**验证内容**:
- HTML 报告可生成
- 报告包含所有必要信息
- 图表正确渲染
- 报告可离线查看

**通过标准**:
- 报告文件完整
- 所有数据正确
- 可在浏览器中正常显示

**失败后果**: WARN - 用户无法获得完整报告

## 4. 验证执行指南

### 4.1 环境准备

1. **软件环境**:
   - 安装指定版本的 Topos Calibrator
   - 安装 ArgyllCMS（记录版本号）
   - 确保系统权限已配置

2. **硬件环境**:
   - 清洁探头镜头/积分球
   - 确认显示器已预热 30 分钟以上
   - 关闭环境光干扰（如可能）
   - 关闭显示器节能功能

3. **显示器设置**:
   - 恢复出厂设置或记录当前设置
   - 关闭动态对比度、环境光自适应
   - 关闭蓝光过滤/护眼模式
   - 记录显示器型号、固件版本

### 4.2 验证流程

1. 执行预检，确认所有 BLOCK 项已解决
2. 记录预检结果
3. 执行探头校准
4. 执行原生测量（建议使用标准测试色块集）
5. 生成 ICC Profile
6. 应用 ICC 并验证
7. 生成 3D LUT（如适用）
8. 验证 3D LUT（如适用）
9. 导出报告
10. 填写验证矩阵表格

### 4.3 数据记录要求

每次验证需要记录以下数据：

- **软件版本**: Topos Calibrator 版本号
- **ArgyllCMS 版本**: argyll-Version 信息
- **操作系统**: 版本号、更新状态
- **探头**: 型号、序列号、固件版本、校正时间
- **显示器**: 型号、固件版本、设置快照
- **环境**: 室温、环境光（如可测）
- **测量数据**: 原始 TI3 文件、ICC 文件、LUT 文件
- **报告**: HTML/PDF 报告

### 4.4 问题分类

验证中发现的问题按以下分类：

| 级别 | 定义 | 示例 |
|-----|------|------|
| BLOCK | 阻止继续使用，必须修复 | 探头无法识别、ICC 无法生成 |
| WARN | 功能受限或结果不理想，可继续使用 | 某显示器特殊设置未检测、精度略低 |
| INFO | 已知限制，不影响核心功能 | OLED 黑场测量时间较长 |
| TBD | 待确认问题，需要进一步验证 | 偶发性测量超时 |

| 操作系统 | 限制 | 影响 | 解决方案/缓解措施 |

| macOS | Night Shift 干扰 | 白点准确性 | 预检检测并提示关闭 |

| Linux | Wayland 不支持 | 显示器识别 | 强制使用 X11 |
| Linux | i2c-dev 权限 | DDC/CI | 配置 udev 规则 |
