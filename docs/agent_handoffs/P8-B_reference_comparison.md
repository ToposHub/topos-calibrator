## 2. 实现思路

### 2.1 文档结构设计

按照任务要求，文档包含五个核心部分：

1. **参考工具概述** - 介绍三种参考工具：
   - DisplayCAL（开源，基于 ArgyllCMS）
   - ArgyllCMS 原生命令（spotread/dispcal/dispread 等）
   - 厂商软件（X-Rite i1Profiler、Datacolor SpyderX）

2. **对比指标清单** - 定义六类关键指标：
   - 白点指标（CCT、Duv、xy 偏移、Delta E）
   - 亮度指标（白场、黑场、对比度）
   - Gamma/EOTF 指标（平均 Gamma、BT.1886 参数）
   - 色域覆盖指标（覆盖率、面积比、RGB xy 坐标）
   - Delta E 指标（平均值、最大值、分布）

3. **对比方法规范** - 确保测量可重复性：
   - 测量条件一致性（同屏同探头同校正文件）
   - 相同色块组（基础 11 点 + 扩展可选）
   - 测量顺序（最小化漂移）
   - 对比执行步骤（5 步流程）

4. **差异分析流程** - 定义差异处理：
   - 三级阈值（一致/需检查/需修正）
   - 三类差异原因（A类算法/B类测量/C类已知）
   - 回滚修正流程（回到 P2/P3/P4）

5. **Reference Report 模板** - 完整的报告结构：
   - A-H 八个章节
   - 必填字段和可选字段说明
   - 状态标记定义（✅ ⚠️ ❌）

## 8. 关键文档内容摘要

### 参考工具对比命令示例

```bash
# Argyll 原生测量白点
spotread -e -N
# 输出: XYZ = 95.05 100.00 108.88, xyY = 0.3127 0.3290 100.0

# DisplayCAL 校准命令
dispcal -v -m -H -q l -t 6500 -g 2.2 -k 0 display_name
dispread -v -m -H -k display_name.cal display_name
colprof -v -q m -D "display_name" display_name
```

### 差异阈值表

| 指标 | 一致阈值 | 需检查阈值 | 需修正阈值 |
|------|----------|------------|------------|
| CCT | ≤ 50K | 50K - 200K | > 200K |
| Gamma | ≤ 0.05 | 0.05 - 0.1 | > 0.1 |
| Delta E 平均 | ≤ 0.5 | 0.5 - 1.0 | > 1.0 |

### 色块组定义

基础对比色块：RGBW + 黑 + 灰阶 0%/10%/20%/50%/80%/100% = 11 点
